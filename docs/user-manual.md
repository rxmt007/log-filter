# LogFilter 用户手册

LogFilter 是一款面向 Windows、macOS 与 Linux 的 Android logcat 桌面查看器，支持设备日志采集、文件浏览、过滤、搜索、高亮、书签、导出与切分。应用采用增量索引和虚拟化渲染处理大型日志文件。

项目已在 macOS Apple Silicon 环境完成 10 GiB 日志基准测试。该结果来自特定软硬件环境，不代表其他平台的运行表现，详见 [10 GiB 基准报告](superpowers/2026-07-06-benchmark-10gb.md)。

> **平台状态**：当前仅在 macOS Apple Silicon 环境完成手动运行测试。macOS 构建尚未进行代码签名和 Apple 公证；macOS Intel、Windows 与 Linux 版本尚未完成手动验证。CI 构建通过不等同于安装包运行验证。
>
> 欢迎通过仓库的 Issues 反馈问题或建议、参与讨论，或提交 Pull Request 帮助改进功能、兼容性与文档。

本手册面向使用者，所有描述均以当前版本的实际行为为准。

---

## 基本工作流

1. **运行应用**：当前版本主要通过源码构建和运行，具体步骤见第 1 章。GitHub Actions 提供的安装包属于开发构建。
2. **选择日志来源**：
   - **设备采集**：通过 USB 连接已启用调试功能的 Android 设备，在左上角设备列表中选择设备，然后点击工具栏的 ▶(Start)开始采集；
   - **文件浏览**：按 `Cmd/Ctrl+O` 或点击工具栏文件夹图标打开 logcat 日志文件。大型文件会在后台建立索引，索引期间仍可浏览已处理的内容。
3. **应用过滤条件**：使用级别芯片(V/D/I/W/E/F)选择日志级别，并在过滤栏中设置 Tag、PID 或内容关键词。多个值以 `|` 分隔，修改后约 0.2 秒应用结果。
4. **搜索日志**：按 `Cmd/Ctrl+F` 聚焦搜索框，输入关键词后查看命中统计，并使用 ↑/↓ 按钮在结果之间跳转。
5. **添加书签**：双击日志行切换书签，使用 `F2`/`F3` 在书签之间跳转。书签会自动保存，并在再次打开同一文件时恢复。

## 1. 安装与运行

### 1.1 从源码构建

当前版本主要通过源码构建和运行。前置条件为 Rust stable 工具链、Node.js 22 与 pnpm；还需安装 Tauri v2 在对应操作系统上要求的系统依赖。

```bash
git clone <仓库地址>
cd log-filter
pnpm install --frozen-lockfile
pnpm tauri dev        # 开发模式直接启动
# 或
pnpm tauri build      # 本机打安装包,产物在仓库根 target/release/bundle/
```

### 1.2 GitHub Actions 开发构建

仓库的 **Desktop Build** 工作流可在手动触发或推送 `v*` 标签时生成三平台安装包。这些 artifact 用于开发测试，不是经过签名和完整平台验证的正式发行版，并会按照 GitHub 的保留策略过期。

| Artifact 名称 | 平台 | 包含文件 | 手动验证状态 |
| --- | --- | --- | --- |
| `logfilter-windows-latest` | Windows | `.msi`(MSI 安装包)、`.exe`(NSIS 安装器) | 未测试 |
| `logfilter-macos-latest` | macOS | `.dmg` | 仅 Apple Silicon 已测试；未签名、未公证 |
| `logfilter-ubuntu-22.04` | Linux(Debian/Ubuntu) | `.deb` | 未测试 |

macOS Intel 尚未完成手动测试。工作流成功表示构建过程完成，不代表对应安装包已在目标系统上通过运行验证。

**获取开发构建：**

1. 打开仓库的 **Actions** 页面，选择 **Desktop Build** 工作流；
2. 进入已完成的运行记录，在 **Artifacts** 区域下载并解压对应平台的文件；若没有可用记录，请按第 1.1 节从源码构建；
3. 按平台安装：
   - **Windows**：运行 `.msi` 或 `.exe` 并按安装向导操作；
   - **macOS**：打开 `.dmg` 并将应用拖入“应用程序”文件夹。由于构建未签名且未公证，系统可能阻止直接运行；
   - **Linux**：运行 `sudo dpkg -i <文件名>.deb`，或使用系统的软件安装器打开。

## 2. 界面总览

窗口从上到下分为四块:

```
┌──────────────────────────────────────────────────────┐
│ 工具栏(第 1 行):设备下拉 · 命令输入框(带预设下拉)     │
│ 工具栏(第 2 行):▶ ⏸ ⏹ 🗑 | 打开 导出 切分 设置 主题 |   │
│                  级别芯片 · 仅标记 | 搜索框 | 行号跳转   │
│ 过滤条:6 个过滤字段 + 3 组高亮                          │
├───┬──────────────────────────────────────────────────┤
│ 小 │  日志表格(书签/行号/日期/时间/级别/PID/TID/Tag/消息) │
│ 地 │                                                  │
│ 图 │                                                  │
├───┴──────────────────────────────────────────────────┤
│ 状态栏:已加载行数 · 当前结果 · 索引进度 · 当前行 · 编码 · 来源 │
└──────────────────────────────────────────────────────┘
```

- **工具栏**:抓取控制(Start/Pause/Stop/Clear)、打开文件(含最近文件)、导出、切分、设置、明暗主题切换、级别芯片、"仅标记"开关、搜索框(带大小写/正则开关和上一个/下一个)、行号跳转框。
- **过滤条**:Tag 包含 / Tag 屏蔽 / PID / TID / 内容包含 / 内容屏蔽 六个字段,以及 3 组关键词高亮,每项都有独立启用开关。
- **表格**:采用虚拟化渲染,仅呈现当前可见区域;大型文件的实际性能取决于文件内容、硬件与运行平台。没有数据时显示空状态,并提供"从设备抓取"和"打开文件"两个入口。
- **Minimap(小地图)**:表格左侧细长条,纵览全局的错误密度(红色)与书签位置(蓝色),可通过点击或拖拽定位。
- **状态栏**:`已加载 N 行`、`当前结果 N 行`(开了"仅标记"会追加提示)、`索引 x%`(索引进行中会标注"进行中")、`当前 第 N 行`、编码、右侧显示数据来源(`adb · 设备序列号` 或文件路径)。

## 3. 从设备抓取日志(adb)

### 3.1 准备

- 设备开启"开发者选项 → USB 调试",用数据线连接电脑;
- 电脑上需要有 `adb`(Android platform-tools)。应用会按以下顺序自动寻找:设置里配置的 ADB 路径 → 系统 `PATH` → 常见 SDK 位置(`ANDROID_HOME`/`ANDROID_SDK_ROOT` 下的 `platform-tools`、macOS 的 `~/Library/Android/sdk/platform-tools`、Linux 的 `~/Android/Sdk/platform-tools`、Windows 的 `%LOCALAPPDATA%\Android\Sdk\platform-tools`)。都找不到时启动抓取会报错,请到设置里手动指定(见第 14 章)。

### 3.2 选择设备

- 左上角是**设备下拉**,每 4 秒自动刷新一次 `adb devices` 的结果;
- 每项显示"型号(或序列号)· 状态",在线设备前有绿点;离线/未授权设备置灰不可选;
- 检测到设备后会自动选中第一台在线设备;没有任何设备时显示"无在线设备"。

### 3.3 命令输入与预设

设备下拉右侧是**命令输入框**。出于安全与解析兼容考虑,**只支持一种命令形态**:

```
logcat -v threadtime -b <缓冲区>
```

- `<缓冲区>` 可选:`main`、`system`、`radio`、`events`、`crash`,且一次只能指定一个 `-b`;
- 不支持其它参数、不支持管道/重定向等复合 shell 写法(输入 `|`、`&`、`;`、`<`、`>` 会直接报错);
- 输入后按 **Enter** 或点击输入框外提交;命令不合法时输入框标红并提示原因,按 **Escape** 可恢复为上次已保存的命令;
- 输入框右侧的下拉是**预设命令**:内置 5 条(对应 5 个缓冲区),用户提交过的合法命令也会自动存为预设(最多额外保存 20 条),选择后即可使用。

### 3.4 抓取控制按钮

| 按钮 | 何时可用 | 行为 |
| --- | --- | --- |
| ▶ **Start** | 未在抓取时 | 按当前命令启动 `adb logcat`,新建一个会话文件并开始写入;表格自动尾随最新日志 |
| ▶ **Resume** | 已暂停时(同一个 ▶ 按钮,悬停提示变为 Resume) | 续抓:从会话文件末尾取出最后一条日志的时间戳,以 `logcat -T "<时间戳>"` 继续抓取。**边界时间戳包含在内,同一毫秒内的日志可能出现少量重复行**,这是为避免遗漏边界日志而采用的行为 |
| ⏸ **Pause** | 抓取运行中 | 暂停:停止 logcat 子进程,已抓内容全部保留,可正常浏览/过滤/搜索 |
| ⏹ **Stop** | 运行中或已暂停 | 结束本次抓取。内容保留可继续查看,再点 ▶ 会开始一次全新抓取 |
| 🗑 **Clear** | adb 模式且有内容时 | 清空当前内容并新建会话文件,重新开始一段干净的抓取 |

**兼容性说明**:`logcat -T <时间>` 在个别老系统上不受支持,此时设备端 logcat 会立即退出,表现为**点 Resume 后日志流自动停止**(按钮回到可 Start 状态)。遇到这种情况请直接点 ▶ 重新开始抓取(会从缓冲区头部重抓)。

### 3.5 会话文件存储

抓取的日志实时写入本地会话文件,文件名形如 `logcat-<毫秒时间戳>.log`,位于设置中的"存储位置"(默认为应用配置目录下的 `sessions/` 子目录)。应用自动清理旧会话,**只保留最近 10 份**;需要长期留存的请用导出功能(第 12 章)。

## 4. 打开文件与最近文件

支持 `logcat -v time` 与 `-v threadtime` 两种格式的日志文件,打开时自动识别。

**操作步骤:**

1. 点工具栏的**文件夹图标**,在下拉中选"打开文件...",或直接按 `Cmd/Ctrl+O`;
2. 在系统文件对话框中选择日志文件;
3. 大文件(GB 级)打开后会先显示已处理内容,同时在后台建立索引——状态栏显示"索引 x% · 进行中",索引期间可以滚动浏览,过滤/搜索的结果会随索引推进逐步补全。

**最近文件**:文件夹图标的下拉里会列出最近打开过的文件(显示文件名,悬停可见完整路径),点击即可重新打开。

## 5. 浏览、列与尾随

### 5.1 表格列

默认列:书签、行号、日期、时间、级别、PID、TID、Tag、消息。

- **显示/隐藏列**:点表头右侧的**列按钮**(网格图标),勾选/取消勾选;"消息"列不可隐藏;
- **调整列宽**:拖拽表头单元格右缘的把手;
- 列的显隐与宽度会自动保存,下次启动保持。

### 5.2 选择与复制

- 单击行选中(状态栏"当前 第 N 行"随之更新);
- 用鼠标拖选表格文本后按 `Cmd/Ctrl+C`,会按当前可见列把选中范围内的**整行**格式化复制(书签列除外)。

### 5.3 尾随最新(仅 adb 抓取模式)

抓取进行中,表格默认**尾随**:新日志到达自动滚到底部。

- **暂停尾随**:向上滚动、点击某行、搜索/跳转/书签导航/拖 Minimap、修改过滤条件,任一操作都会暂停尾随,便于检查历史日志;
- **恢复尾随**:手动滚动到表格最底部即自动恢复;或点击表格**右下角的"追最新"图标按钮**(双下箭头,仅在抓取运行中且未尾随时出现)。

## 6. 过滤

所有过滤条件**叠加生效**(同时满足才显示),修改后约 0.2 秒自动应用。当前过滤条件会随配置保存,重启应用后自动恢复。

### 6.1 级别芯片

工具栏"级别"区域:`全部` + `V / D / I / W / E / F`(Verbose/Debug/Info/Warning/Error/Fatal)。

- 点击单个字母芯片切换该级别的显示/隐藏;点"全部"恢复全选;
- **注意**:只要选择了级别子集(不是全选),**没有级别字段的行会被一并隐藏**——例如 logcat 缓冲区分隔行 `--------- beginning of main`。如需查看这类行,请把级别恢复为"全部"。

### 6.2 仅标记

级别芯片旁的"仅标记"芯片:开启后只显示打了书签的行(详见第 10 章)。

### 6.3 六个过滤字段

| 字段 | 含义 | 正则开关 |
| --- | --- | --- |
| **Tag 包含**(+) | 只显示 Tag 匹配的行 | 有 |
| **Tag 屏蔽**(−) | 隐藏 Tag 匹配的行 | 有 |
| **PID** | 只显示指定进程号的行 | 无 |
| **TID** | 只显示指定线程号的行 | 无 |
| **内容包含**(+) | 只显示消息内容含关键词的行 | 有 |
| **内容屏蔽**(−) | 隐藏消息内容含关键词的行 | 有 |

**操作方法:**

1. 点字段左侧的**开关**启用(未启用的字段不参与过滤);
2. 在输入框填写条件,**多个值用 `|` 分隔**,例如 PID 填 `12043|146`、Tag 包含填 `ActivityManager|WindowManager`;
3. Tag 和内容四个字段各有 `.*` **正则开关**:开启后按正则表达式匹配,关闭时按普通子串匹配(`|` 分隔多值)。

> 提示(adb 模式):修改任何过滤条件都会暂停尾随,改完后点右下角"追最新"恢复。

## 7. 高亮(3 组)

过滤条下方有 **3 组关键词高亮**,只给命中文本上色、**不影响过滤结果**。

每组包含:

- **启用开关**;
- **关键词输入框**;
- `.*` **正则开关**;
- `Aa` **大小写敏感开关**;
- **颜色选择**:yellow / green / blue / purple。

命中的文本在"消息"列中以对应颜色标出。若同一段文本同时命中搜索词和高亮词,**优先显示搜索命中的样式**。

---

## 8. 搜索

工具栏右侧的搜索框可通过 `Cmd/Ctrl+F` 聚焦:

1. 输入关键词,约 0.18 秒后自动在**当前结果**中全量搜索,框内计数显示 `当前命中行号 / 命中总数`;
2. `Aa` 切换大小写敏感,`.*` 切换正则模式;
3. 点 **↑(上一个)/ ↓(下一个)** 在命中之间跳转,命中行居中显示并选中;
4. 清空搜索框即清除搜索状态。

搜索命中的文本在消息列中以高亮标记显示。adb 模式下,输入或切换搜索选项会暂停尾随。

---

## 9. 行号跳转

搜索框右侧是**行号跳转框**,可通过 `Cmd/Ctrl+G` 聚焦:

1. 输入目标**行号**(指原始文件/会话中的行号,即"行号"列显示的数字);
2. 按 **Enter** 或点"跳转",目标行居中显示并选中。

**注意**:如果目标行被当前过滤条件隐藏(不在当前结果里),跳转不会发生;请先放宽过滤条件再跳。

---

## 10. 书签

### 10.1 标记与取消

- **双击**某一行:切换该行书签(行首书签列出现/消失图标);
- **右键**某一行(或先拖选多行文本再右键):弹出菜单,选"**标记选中行**"批量打书签,或"**取消标记**"批量移除。

### 10.2 书签导航

- **F2**:跳到上一个书签;**F3**:跳到下一个书签(到头/到尾会回绕);
- 只在**当前过滤结果可见**的书签间跳转;
- 配合"仅标记"芯片可以只看所有书签行。

### 10.3 持久化

书签自动保存在**日志文件同目录**的侧车文件中,文件名为 `<日志文件名>.lfbookmarks.toml`(例如 `device.log` 对应 `device.log.lfbookmarks.toml`)。下次打开同一文件时书签自动恢复。

**注意**:若日志所在目录**只读**(如挂载的只读盘、无写权限的目录),打/取消书签时保存会失败并报错。请把日志复制到可写目录后再打书签。

## 11. Minimap(小地图)

表格左侧的细长条是整个当前结果的纵览:

- **红色刻度 = 错误密度**:每个刻度代表一段区域内的 Error/Fatal 行,**颜色越深(越不透明),该区域错误越密集**;
- **蓝色段 = 书签位置**(开启"仅标记"时整条显示为连续蓝色);
- **浅色滑块 = 当前视口**在全文中的位置。

**操作方法:**

- **点击**小地图任意位置:表格定位到对应区域;
- **按住拖拽**:连续滚动定位(点在视口滑块内拖动为抓取式拖动,不跳变);
- 拖动小地图会暂停尾随。

## 12. 导出

点工具栏的**导出图标**(下载箭头)打开导出对话框。

**操作步骤:**

1. 选导出模式:
   - **当前结果**:再从下拉选择内容——`全部日志` / `当前结果`(默认,即当前过滤后的行)/ `已标记`(书签行)/ `错误/Fatal`;
   - **行号范围**:填开始行、结束行(原始行号);
2. 选**输出文件**:点文件夹按钮打开保存对话框(默认名 `logfilter-export.log`,支持 `.log`/`.txt`),或直接输入路径;
3. 点**导出**:按钮变为"导出中 · 已写入 N 行"实时显示进度;导出期间出现**取消**按钮,点它中止;
4. 完成后对话框内显示"已导出 N 行 · M bytes";同时窗口会弹出全局 **toast 提示**,附带"**打开所在目录**"按钮,用于在文件管理器中定位导出文件。即使导出过程中关闭对话框,完成时仍会显示 toast。

导出在后台分块进行,不会卡住界面,大文件导出期间可以继续浏览日志。

---

## 13. 切分大文件

点工具栏的**切分图标**打开"切分日志"对话框,把一个大日志文件切成多个小文件。

**操作步骤:**

1. **源文件**:默认为当前打开的文件,可点文件夹按钮另选;
2. **输出目录**:默认为设置中的存储位置,可另选;
3. **方式**:
   - **按行数**:每份固定行数(默认 100000 行);
   - **按字节**:每份约定字节数,切分始终按完整行边界进行,因此每份实际大小会略有出入;
4. 点**切分**:按钮显示"切分中 · 已生成 N 份"进度;完成后显示"已生成 N 个文件 · M bytes"。

## 14. 设置

点工具栏的**齿轮图标**打开设置对话框,修改后点**保存**生效:

| 设置项 | 说明 |
| --- | --- |
| **主题** | 浅色 / 深色(也可通过工具栏的太阳/月亮按钮切换) |
| **配置文件** | 只读展示当前配置文件路径 |
| **编码** | `UTF-8`(默认)或 `Local`(本地编码),影响日志文本的解码方式 |
| **存储位置** | adb 抓取会话文件的保存目录;留空用默认位置 |
| **ADB 路径** | 手动指定 adb 可执行文件;留空则自动在 PATH 和常见 SDK 位置扫描 |
| **字体** | 表格字号,10–20 |
| **行高** | 表格行高,16–32 |

配置以 TOML 格式存放在各平台标准位置:Windows `%APPDATA%\LogFilter`、macOS `~/Library/Application Support/LogFilter`、Linux `~/.config/logfilter`。窗口尺寸、表格列布局、最近文件、上次的过滤条件、命令预设等都会自动记忆。

## 16. 常见问题(FAQ)

**Q:设备下拉显示"无在线设备"?**
A:确认设备已开启 USB 调试且数据线连接正常;在设备上允许调试授权弹窗。下拉每 4 秒自动刷新,无需手动刷新。若列表里有设备但置灰,说明它处于 offline/unauthorized 状态,重插数据线或在设备上重新授权。

**Q:点 Start 报错 "adb executable was not found"?**
A:电脑上没有 adb 或不在自动扫描范围内。打开设置 → **ADB 路径**,点文件夹按钮选中 adb 可执行文件(Windows 为 `adb.exe`)并保存;或安装 Android platform-tools 并加入 PATH。

**Q:如何清空当前日志并重新抓取?**
A:点工具栏的 🗑(Clear)。应用会清空当前内容,新建会话文件并继续抓取。

**Q:如何确认大文件索引已经完成?**
A:文件打开后即可浏览已处理内容。状态栏中的"索引 x%"显示"进行中"时,后台仍在建立索引,过滤和搜索结果会随进度补全;达到 100% 后覆盖完整文件。

**Q:Resume 续抓后看到重复的日志行?**
A:正常现象。续抓用 `logcat -T <最后时间戳>`,边界毫秒内的日志会被再次收取,因此同一毫秒可能出现少量重复,不会漏日志。

**Q:为什么 Resume 后日志流立即停止?**
A:个别老设备的 logcat 不支持 `-T <时间>` 参数,进程会立即退出,表现为流自动停止。请直接点 ▶ 重新开始一次全新抓取。

**Q:为什么行号跳转未生效?**
A:目标行被当前过滤条件隐藏了。恢复级别为"全部"、关闭相关过滤字段后再试。

**Q:为什么保存书签时报错?**
A:书签保存在日志文件同目录的 `.lfbookmarks.toml` 侧车文件里,目录只读时会保存失败。把日志文件复制到可写目录后再打开即可。

**Q:`--------- beginning of main` 这类分隔行不见了?**
A:当前选择了级别子集。这类行没有级别字段,只在级别为"全部"时显示。
