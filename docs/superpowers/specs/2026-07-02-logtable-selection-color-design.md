# LogTable 选中颜色连续性设计

## 背景

当前表格复制选区使用整行蓝底,但 `W/E/F` 等级行和已标记行各自有背景色。因为这些背景规则的 CSS 优先级高于普通选中态,拖选范围内会出现浅黄、浅红等断层,视觉上不像连续选中。

## 方案

采用方案 B:修复优先级并换成更克制的选中蓝。

- `data-copy-selected="true"` 是复制选区的最高视觉状态。
- 选中态必须覆盖 `W/E/F` 等级背景和已标记行背景,保证整段选区连续。
- 选中底色从较重的蓝色调整为更浅的 `#cfe3ff`,文字使用 `#17345f`。
- 等级含义仍保留在 `level` 字母本身,选中时不再用整行等级底色表达。
- 深色主题维持半透明蓝色,降低不必要的亮度压迫。

## 验证

结构契约脚本需要覆盖两点:

- CSS 明确包含 `data-copy-selected + data-level W/E/F` 和 `data-marked` 的覆盖规则。
- 浅色主题选中 token 使用新的克制色值。
